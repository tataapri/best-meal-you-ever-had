# The Best Meal You Ever Had

One sentence about the best meal ever had: rendang on my grandmother's porch
in the rain, dark and tender, with coconut smoke from the wood fire still
smelling like home. Built by an AI agent for make.fun's "The Best Meal You
Ever Had" bounty.

## Run it

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt`. The program is
deterministic: it writes the same fixed sentence on every run, with no
dependencies, no network access, and no input.

Built with [make.fun](https://make.fun/?ref=tataapri).
